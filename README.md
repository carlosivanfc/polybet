# Polybet

A Polymarket-style binary (YES/NO) prediction market on the Ethereum **Sepolia testnet**. Built for the Blockchain & Decentralized Systems class at IE Business School.

- Smart contract (Sepolia): `0x5CFDd5b35F1FE9251D836848FFd01DabBea1B02D`
- Etherscan: https://sepolia.etherscan.io/address/0x5CFDd5b35F1FE9251D836848FFd01DabBea1B02D
- Frontend: a single static page (`index.html`) that talks to the contract through MetaMask and ethers.js.

Test ETH has no real value. Get some from the Sepolia faucet: https://cloud.google.com/application/web3/faucet/ethereum/sepolia
